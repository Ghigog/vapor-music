## Walkthrough for Window Management & Playback UI Redesign (WIN-001, WIN-002, UI-001)

### Details
1. **Window Corner Resizing (`WIN-001`)**: Replaced manual coordinate mathematics with 8 invisible, dedicated `Control` nodes acting as drag handles positioned around the visual borders of `$AppWindowFrame/LayoutRoot`. Godot manages the cursor shape changes automatically. Set window stretch mode in `project.godot` to `disabled` so text/elements stay constant at 1:1 pixel size and reflow/stretch without shrinking.
2. **Sidebar Window Dragging (`WIN-002`)**: Overrode `_gui_input` in `sidebar.gd` to change window coordinates on drag while ensuring buttons still receive click events properly. Configured intermediate mouse filters to `MOUSE_FILTER_PASS` so that clicks on the blank spaces of the sidebar drag the window. Also added this drag handler to the mobile bottom bar.
3. **Vertical & Horizontal Progress Layouts (`UI-001`)**: Created `vertical_progress.gd` script for drawing a minimalist top-to-bottom bar on desktop. Moved control buttons into the sidebar as square tiled buttons. Restructured mobile layout to merge TabBar and MiniPlayer into a single panel containing: Library | Search | Back | Play/Pause | Next | Settings | More. Removed the duplicate TabBar node from the project entirely and placed the merged bar flush to the bottom. Squared the top edges of the bottom panel to match the progress bar, and kept bottom edges rounded to fit the window corners. Removed all shadows from glass panels globally in `ThemeManager.gd` to match flat Apple widgets. Rounded the top-left and bottom-left outer edges of the sidebar to match the parent window corners, leaving the inner right edges sharp. Rounded the bottom-left corner of the "Back" button in the sidebar stylebox overrides, matching the sidebar's bottom-left radius. Made the progress slider thumb visible at all times.
